# 注文一覧の打ち切りを設定で切り替えられるようにする

案: [ideas.md](../../ideas.md)。ユーザー了承済み。実装は新しいセッションで行う。優先度は低い（任意）。

## 背景

実機で「適格請求書をフォルダーに保存」を10月分で実行したところ、取得用タブが注文履歴を年初（2026年1月）まで遡った。既存の `collectOrders`（`core.js`）が、他の拡張による全件展開に備えて「対象月に関係なく最後のページまで追う」作りのため（想定どおりの既存挙動）。保存先はダウンロードではなく選んだフォルダーで、一覧取得が終わるまで何も書かれない。待ち時間は実害が小さい。

## 方針

- 設定（チェックボックス）で、対象月より古いページに達したらページ送りを打ち切る挙動を切り替えられるようにする。月別PDF出力にも効く共通の設定にする。既定値は実装時に決める（高速化なら ON、取りこぼし回避なら OFF）。
- 打ち切り条件: そのページの注文がすべて対象月より古いとき。一覧は新しい順なので、境目のページは続けて読み、次の全部古いページで止まる。対象月と新しい月が混ざるページでは止めない。
- `parseOrders` が「全注文が対象月より古いか」を返し、`collectOrders` は引数（オプション）で打ち切りを有効にする。既存テストの呼び出しは変えない。
- 設定の保存は `localStorage`（try/catch で失敗時は既定値）。`storage` 権限は足さない。
- テスト: 打ち切り ON で後続ページを読まない／OFF で最後まで読む／境目ページの扱い／他拡張が順序を崩した一覧で取りこぼさないこと。
- README・CHANGELOG・`app.html` の説明も更新する。
- 上流へは PR を出さない前提で、`personal` にのみコミットする。
